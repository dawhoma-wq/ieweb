Respaldo y restauración

Exporte o importe toda la base de datos local del sistema en formato JSON. El sistema está dimensionado para gestionar como mínimo 50 estudiantes.

Plantilla y mantenimiento de datos

El sistema arranca con la base de datos en cero, lista para registrar estudiantes y calificaciones reales. Si lo necesita para pruebas, cargue 50 estudiantes de muestra. Use "Reiniciar base de datos" para dejar todo en cero cuando lo requiera (se conservan las cuentas de usuario y la configuración institucional).

Firma digital para validar reportes

Dibuje las firmas (docente y director) que se incrustarán automáticamente en todos los PDF que emita el sistema. Cada documento se firma además con un código criptográfico único (SHA-256) para validar su autenticidad.

Las firmas se almacenan localmente en este equipo y se incrustan en los PDF generados como imagen vinculada al titular. Adicionalmente, cada reporte incluye un código de validación único (hash SHA-256) calculado con los datos institucionales, fecha de emisión y contenido del reporte.

Verificar autenticidad de un documento

Introduzca el código de validación impreso en el sello inferior de un PDF para comprobar si fue emitido en este sistema y reconstruir sus datos.
